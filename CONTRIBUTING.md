\# Contributing to Martian Climate Dashboard



Thank you for your interest in contributing!



\## 🚀 Getting Started



\### 1. Clone the Repository



```

git clone <repo-url>

cd Martian-Climate-Dashboard

```



\### 2. Install Dependencies



This project requires Flutter. Install packages via:



```

flutter pub get

```



\## ▶ Running the Project



```

flutter run

```



\## 🧩 Branch Naming Convention



Use:



```

feature/<short-description>

fix/<short-description>

doc/<short-description>

```



Example:



```

doc/add-contributing-guide

```



\## 📌 Commit Message Format



Use standard commit messages:



\* `feat:` – new feature

\* `fix:` – issue fix

\* `docs:` – documentation

\* `refactor:` – code cleanup



Example:



```

docs: added CONTRIBUTING guidelines

```



\## ✔ Submitting a Pull Request



1\. Create a branch

2\. Make your changes

3\. Commit using guidelines

4\. Push to your fork

5\. Open a Pull Request



Thanks for contributing!
